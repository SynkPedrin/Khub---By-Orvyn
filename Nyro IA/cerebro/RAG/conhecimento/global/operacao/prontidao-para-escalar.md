# Prontidão para Escalar — está pronto para crescer?

## Quando usar
Antes de investir pesado em crescimento (mais verba, mais gente, nova unidade). Escalar um processo quebrado só cria uma bagunça maior, mais rápido.

## As seis dimensões
- **Product-market fit:** a retenção é forte? Os clientes puxam o produto?
- **Unit economics:** cada cliente é lucrativo? Qual o período de payback?
- **Processo repetível:** você adquire clientes por um processo repetível — não heroico?
- **Capacidade de time:** você tem (ou consegue contratar) gente para 3–5x o volume?
- **Infraestrutura/sistemas:** suas ferramentas e processos sobrevivem a 10x de carga?
- **Caixa/runway:** há capital para financiar o período de escala?

## Níveis de prontidão
- **Não pronto:** menos de 3 dimensões fortes — foque em fundação antes de escalar.
- **Se aproximando:** 3–4 dimensões fortes — resolva as lacunas enquanto planeja a escala.
- **Pronto:** 5–6 dimensões fortes — execute o plano de escala.

## Aplicação no KHUB
A Nyro pode avaliar "processo repetível" e "unit economics" com dados reais do CRM (CAC via integrações de ads, LTV via recorrência no pipeline) antes de recomendar que o cliente aumente o orçamento de tráfego.

## Aviso
Escalar um processo quebrado só cria uma bagunça maior, mais rápido. Conserte antes de escalar.
